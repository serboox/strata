Где на самом деле уходит времяWhere the time really goes

Разбор записанной сессии pi на Strata (128 ходов, 4 компактации; считались только агрегаты, содержимое не копировалось). Декодирование было лишь около 9% времени; остальное это чтение промпта, и в нём три отдельные причины.Analysis of a recorded pi session on Strata (128 turns, 4 compactions; only aggregates were counted, no content was copied). Decoding was only about 9% of the time; the rest is prompt reading, and it has three separate causes.

  • Цикл. 67 вызовов одной и той же команды (git diff | grep | head -N с другим N) вернули одинаковый результат: 69 из 127 результатов по 2948 символов, 82,5 тыс. токенов или 51% всех токенов результатов.A loop. 67 calls of one command (git diff | grep | head -N with a different N) returned the same output: 69 of 127 results of 2948 characters, 82.5K tokens or 51% of all tool-result tokens.
  • Компактация. Запрос на сводку читается с нуля (12-23 тыс. токенов, другой промпт, кэша нет), сводка пишется 1,2-3,9 тыс. токенов, а следующий ход читает хвост заново: 20-30 тыс. токенов, потому что pi считает токены как символы/4, а код даёт 2,8 символа на токен. Пять холодных ходов после компактаций это 132,7 тыс. токенов (36% всего).Compaction. The summary request is read from scratch (12-23K tokens, a different prompt, no cache), the summary is written at 1.2-3.9K tokens, and the next turn reads the kept tail again: 20-30K tokens, because pi counts tokens as characters/4 while code gives 2.8 characters per token. Five cold turns after compactions are 132.7K tokens (36% of all).
  • Номера строк. Инструмент read отдаёт файл без номеров строк, и модель называет file:LINE наугад.Line numbers. The read tool returns a file without line numbers, so the model guesses file:LINE.

Что делает расширениеWhat the extension does

Папка tools/pi-strata (ветка pi_strata_extension), подключается через tools/spi: каталог extensions профиля монтируется в песочницу только на чтение.The folder tools/pi-strata (branch pi_strata_extension), loaded through tools/spi: the profile's extensions folder is mounted into the sandbox read-only.

Охрана от цикловThe loop guard

Живая проверка: семь команд head -n N small.txt с одинаковым выводом. pi без расширения вернул семь полных копий. С расширением: первая полная, вторая-четвёртая заглушки, пятая и шестая отклонены, седьмая остановила прогон. На записанной длинной сессии охрана (скрипт scripts/replay-guard.ts) отклоняет первый повтор на ходу 66 и останавливает прогон на ходу 68: 60 ходов после него не состоялись бы.Live check: seven commands head -n N small.txt with identical output. pi alone returned seven full copies. With the extension: the first full, the second to fourth stubs, the fifth and sixth refused, the seventh stopped the run. On the recorded long session the guard (script scripts/replay-guard.ts) refuses the first repeat at turn 66 and stops the run at turn 68: the 60 turns after it would not have happened.

РегрессииRegressions

Два других задания дали те же ответы и верную правку с расширением и без него: шесть вопросов о коде (ответы совпали дословно; с расширением прочитано 906 токенов вместо 2208) и переименование константы через edit (старого имени не осталось, файл компилируется; с расширением модель прочитала весь пронумерованный файл, поэтому 91 с против 35 с, это различие траектории).Two other tasks gave the same answers and a correct edit with and without the extension: six questions about the code (the answers matched word for word; 906 tokens read with the extension against 2,208) and a constant rename through edit (no old name left, the file compiles; with the extension the model read the whole numbered file, hence 91 s against 35 s, a difference of trajectory).

Границы. Номера строк добавляют около 3 токенов на строку, в среднем 19% на шести измеренных файлах (13-30%). Лимит и отказ могут скрыть то, что модели было нужно (маркер говорит, как это получить). Записка до 300 слов хранит меньше, чем длинная сводка. Охрана от циклов проверена на одной записи, живом тесте и юнит-тестах (62 теста). Независимый обзор кода нашёл 9 замечаний (3 серьёзных: блокировка подряд идущих правок одного файла, порча текста при вырезании номеров строк, потеря сообщений при сдвиге границы компактации), все исправлены до коммита. Сравнения на одной модели, один прогон на вариант, шум по времени 10-20%.Limits. Line numbers add about 3 tokens per line, 19% on average over six measured files (13-30%). The cap and the refusal can hide something the model needed (the marker says how to get it). A note of up to 300 words holds less than a long summary. The loop guard was checked on one recording, a live test and unit tests (62 tests). An independent code review found 9 issues (3 serious: blocking consecutive edits of one file, corrupting text when line numbers are stripped, losing messages when the compaction cut moves), all fixed before the commit. Comparisons use one model, one run per variant, and a timing noise of 10-20%.
